# 發布說明 - 2026-08-25 (V1.3.5)

## 介面與體驗升級

### 1. 導入 QTabWidget 三分頁導覽結構
- 主設定區塊全新升級為三大清楚分頁：
  - **一般設定**：畫質預設、地圖風格、視角模式、軌跡顏色、資訊面板等核心選項。
  - **進階設定**：自訂尺寸、幀率 (FPS)、NVENC 編碼參數、鏡頭視野、快取設定與 Auto Tune 效能調校。
  - **子進度條**：各 Worker 平行程序之即時子進度監控面板。
- 移除原「進階設定」折疊按鈕，由分頁標籤直接切換，操作更直覺俐落。

### 2. 限制主視窗最大寬高
- 設定視窗最大尺寸為 `1020 × 780` px，預設開啟為 `960 × 720` px，徹底消除過度延伸與垂直跳動問題，各尺寸螢幕皆維持最舒適精美之版面比例。

### 3. 渲染自動切換進度分頁
- 當點擊「開始渲染」或「效能測試」時，介面會自動切換至「子進度條」分頁，方便即時觀察各多程序執行狀態。
