# 發布說明 - V1.4.0 (2026-09-10)

## 🚀 新增功能與重點改善

1. **3D 地形投影與運鏡幾何重構**：
   - **全新 3D 透視投影矩陣**：重構相機座標轉換，精確定義相機光軸深入螢幕前方 (`zc`) 與螢幕垂直高程軸 (`yc`)，顯著提升 3D 鳥瞰視角透視真實度與立體空間感。
   - **3D 騎乘點位 100% 精準置中**：導入精確三角幾何後撤計算公式 (`d_behind = cam_alt * sin(pitch)`)，徹底解決 3D 模式下騎乘點偏離畫面正中央的問題。
   - **海平面截斷防護**：將海洋 DEM 瓦片水深負值全面截斷為 0m 海平面，杜絕沿海或環島路線海水倒灌、海面凹陷或懸空破面情況。
   - **相機高度幾何補償**：相機 Z 軸隨俯角精準維持垂直高度，運鏡與視角切換更自然流暢。

2. **主介面與路線媒體管理排版優化**：
   - 精簡控制項文字，最佳化控制面板視覺密度與操作空間。
   - 新增依里程自動時長計算控制項（秒 / 100km），長途騎乘動畫時長配置更便利。
   - 最佳化主視窗預設尺寸與響應式排版佈局。

3. **版本號同步升級**：
   - 核心套件與視窗標題全面升級至 **V1.4.0**。
