# GPX Ride Renderer V1.4.0 發布說明 (Release Notes)

發布日期：2026 年 9 月 10 日  
適用平台：Windows 10 / 11 64-bit

---

## 🌟 重點亮點 (Highlights)

- **3D 真地形透視投影幾何重構**：全新相機座標系透視轉換矩陣推導，徹底告別視角變形與透視失真。
- **3D 騎乘指示點 100% 精準置中**：嚴謹三角幾何後撤補償算法，騎乘游標與軌跡在任何俯角下精確鎖定於畫面正中心。
- **海平面截斷防護**：海洋 DEM 水深負海拔全面歸零，根除沿海/環島路線地表下陷與海水倒灌破面。
- **路線媒體管理器深度整併**：原生整合至主視窗第三分頁，支援所見即所得 (WYSIWYG) 縮放預覽與雙向即時同步。
- **軌跡顏色判定修復**：修正「經典橘」色彩識別，並確保多程序並行渲染 (Parallel Workers) 色彩設定完全一致。
- **全新現代化預設設定**：開箱即用 3D 真地形 + 衛星影像 + 1080p 直式短影音規格。

---

## 🚀 詳細更新內容

### 1. 3D 地形投影與運鏡幾何重構 (3D Terrain & Camera Projection)
- **相機座標系透視轉換重構**：深入推導並重構 `terrain_3d.py` 的相機幾何投影模型，將深入螢幕前方之深度軸 (`zc`)、垂直向上之高程軸 (`yc`) 與橫向軸 (`xc`) 精確定義，使 3D 鳥瞰視角空間透視更具真實感與層次感。
- **3D 騎乘指示點 100% 精準置中**：重構 `renderer.py` 中 3D 視角中心點後撤計算公式，改採嚴謹幾何投影補償 `d_behind = cam_alt * sin(pitch)`，徹底解決舊版切線估算偏差導致騎乘點偏離畫面正中央的問題。
- **海洋 DEM 海平面截斷防護**：在 3D 地形渲染流程中導入 `dem_grid = np.maximum(dem_grid, 0.0)`，將海洋瓦片負海拔截斷為 0m 海平面，杜絕沿海或跨海路線海水倒灌、海面凹陷或懸空破面。
- **透視焦距平滑化與高度補償**：調整透視縮放基準 `R = view_margin * 0.85`，視距縮放過渡自然；相機高度隨俯角自動進行餘弦幾何補償，仰角調節時相機對地高度維持恆定。

### 2. 路線媒體管理分頁深度整合 (UI/UX Integration)
- **原生分頁整合 (Single Window)**：原先獨立彈出的媒體管理視窗全面重整為主視窗原生分頁（Tab 3：路線媒體管理），操作流程一氣呵成。
- **所見即所得 (WYSIWYG) 預覽畫布**：
  - 預覽區內建地圖風格、視角模式與影片解析度切換選單，支援防遞迴雙向即時連動，隨調隨看。
  - 依目標解析度與畫布比例動態縮放照片卡片、文字大小、邊框圓角與指示標記，實現預覽畫面與最終匯出 MP4 影片 100% 一致。
- **HUD 資訊面板即時疊加預覽**：支援速度儀表板、路線縮圖、高度剖面圖等多選即時預覽與排版對齊。
- **自動時長與節奏控制**：新增依 GPX 總里程自動計算動畫秒數控制項（可自訂秒數 / 100km，預設 60 秒/100km），長程耐力騎乘與短程衝刺皆能保持一致舒適的動畫節奏。
- **精簡介面視覺設計**：全面精簡按鈕標籤文字、重構 EXIF 與 GPS 比對狀態展示卡片，視覺層次更加俐落清晰。

### 3. 核心邏輯與穩定性修復 (Core & Bug Fixes)
- **軌跡顏色「經典橘」色彩修復**：修正 `_build_track_colors()` 針對經典橘色方案的比對邏輯，徹底解決舊版本被強制套用 `plasma` 速度漸層色彩的重大問題。
- **多程序序列化配置同步**：將 `TRACK_COLOR_SCHEME` 納入 `config.py` 的 `RUNTIME_CONFIG_KEYS`，確保所有並行渲染 Worker 子程序正確繼承軌跡色彩。
- **未載入 GPX 防護**：修復未載入 GPX 檔案時切換至媒體分頁拋出的 `AttributeError` 崩潰，並修正繪圖結束時 `QPainter` 生命週期管理。

### 4. 預設渲染設定全面升級 (Modernized Defaults)
- **底圖風格**：預設採用「**4. 衛星影像**」(`Esri.WorldImagery`)。
- **視角模式**：預設採用「**3D 真地形**」(`3D-Terrain`)。
- **視距邊距 (View Margin)**：預設優化為緊湊立體的 **`800.0`**。
- **輸出規格**：預設採用社群最廣泛應用的 **`1080p 直式 (1080×1920)`** 規格。

### 5. Windows 打包管線最佳化 (Packaging & Release Tools)
- **Conda 環境相容性強化**：修復 PyInstaller 打包時遺漏 `libffi`、`_ctypes` 等底層依賴庫的問題。
- **Release Manager GUI 升級**：修正發布管理工具啟動打包子程序時 PATH 缺少 `Library/bin` 的環境問題，確保開箱即用綠色可攜式 EXE 穩定產出。

## 💻 系統需求與使用說明

1. **系統需求**：Windows 10 / 11 64-bit。
2. **免安裝使用**：下載解壓縮後直接執行 `GPX_Ride_Renderer.exe` 即可使用（內建 Python、PySide6 與 FFmpeg 核心）。
3. **硬體加速建議**：建議搭配 NVIDIA 獨立顯卡啟用 NVENC 硬體加速以獲得最佳渲染效能。
