# 發布說明 - 2026-09-03 18:42

## 🚀 新增功能與重點改善

1. **路線媒體管理器（Route Media Manager）重大升級**：
   - **渲染設定全面同步**：在媒體管理器中直接同步主畫面的 6 大關鍵設定（地圖風格、視角模式、解析度預設、軌跡顏色、資訊面板 HUD、Local Zoom），無須返回主畫面即可隨時切換微調。
   - **依照圖資風格載入對應背景**：照片/影片預覽區現在會依照您所選的地圖風格（暗黑、衛星、街道等），即時抓取並呈現對應風格的背景地圖。
   - **所見即所得的資訊面板 HUD 預覽**：媒體預覽畫布新增即時面板預覽，隨選即可預覽「速度與里程 HUD」、「路線小地圖」與「高程剖面」在影片中實際呈現的位置與比例。
   - **固定清晰路線軌跡底圖**：全路線點位預覽的底圖固定使用高對比 Google 街道圖，讓路線與拍攝點位的對應更加清晰易辨。

2. **自訂複選下拉選單支援（Checkable Dropdown）**：
   - 資訊面板全面升級為支援複選的下拉選單，點選任一項目皆可流暢連續勾選，並即時在選單標題呈現當前已啟用的面板組合。

3. **主畫面「設定摘要」介面美化與狀態修正**：
   - **現代化卡片式分區排版**：將原本擁擠的文字摘要重新規劃為「路線與地圖」、「視角與畫質」、「資訊面板 HUD」、「軌跡視覺」四大分類卡片，層次分明、美觀易讀。
   - **無 GPX 狀態提示**：未載入 GPX 檔案前，總時長清楚提示「請先匯入GPX」，取消原先易造成誤解的預設時長顯示。
   - **即時數據聯動刷新**：於媒體管理器中新增、刪除、調整相片或修改偏移後，返回主畫面時設定摘要立即自動刷新為最新數據。
