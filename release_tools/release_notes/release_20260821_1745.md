# 路線媒體管理器全面升級與體驗優化 (2026-08-21)

本版本針對「路線媒體管理器」進行全面升級，帶來更清晰的地圖預覽、更流暢的操作手感，以及更直覺的相片手動對齊與編輯體驗。

## ✨ 新增功能

* **Google 街道底圖動態清晰度換算**：地圖預覽全面導入可視範圍動態瓦片載入機制，拉近放大時自動載入高解析度 Google 街道地圖，街區、道路與地名保持清晰銳利不模糊。
* **相片路線位置滑桿**：右側編輯區新增路線位置滑桿，拖曳即可直覺調整相片在路線上的位置，地圖上的標記點與里程氣泡即時同步移動並自動聚焦。
* **清單內直接編輯里程與說明**：左側媒體清單欄位開放雙擊直接修改「匹配里程」與「自訂說明」，無需切換即可快速自訂。
* **個別媒體快速刪除**：清單欄位新增 `🗑️ 刪除` 按鈕，可將不需要的相片自本次路線排除。

## 🚀 體驗與效能優化

* **無感即時自動儲存**：移除舊式手動套用按鈕，無論透過滑桿、輸入框或表格直接編輯，所有修改均即時自動儲存並雙向同步。
* **消除版面排版抖動**：固定相片預覽視框與頂部控制群組高度，徹底解決切換直式/橫式相片時介面外框忽高忽低的問題。
* **滑鼠游標中心平滑縮放**：地圖縮放以滑鼠游標所在位置為錨點平滑放大/縮小，搭配軌跡線向量化繪圖，大幅提升地圖操作流暢度。
