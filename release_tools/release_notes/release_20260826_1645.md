# 發布說明 - 2026-08-26 (V1.3.5)

### 1. 渲染進度條全面升級為圓形進度環
- 主進度條與 6 個 Worker 子進度條全面升級為現代化圓形進度環 (PyCircularProgress)。
- 主進度條採用科技青藍光環，子進度條採用亮藍光環，並搭配立體陰影特效，呈現更直覺洗鍊。

### 2. Windows 系統深淺色主題自動自適應
- 自動偵測 Windows 系統與 Qt 的深色/淺色主題模式。
- **百分比文字自適應**：深色模式自動顯示純白文字，淺色模式自動切換為高對比深墨藍黑文字，徹底解決淺色背景下白底白字看不清的問題。
- **底軌與陰影自適應**：底軌與陰影濃度隨深淺主題智慧調整，並支援 Windows 主題切換時即時變更配色。

### 3. 排版整合與架構精簡
- 所有進度條元件完美整合於「渲染進度」分頁中，並清理歷史冗餘 UI 檔案。
