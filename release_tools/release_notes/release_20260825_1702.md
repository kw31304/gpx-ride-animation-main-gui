# 發布說明 - 2026-08-25 (V1.3.4)

## 新增功能與重大升級

### 1. 頂部主選單列 (Menu Bar)
- 新增完整的頂部選單系統，包含「檔案」、「編輯與工具」、「檢視」、「設定」與「說明」五大選單。
- 支援標準快捷鍵操作（如 `Ctrl+O` 開啟 GPX、`Ctrl+S` 指定輸出、`Ctrl+M` 媒體管理、`Ctrl+T` 效能測試、`Ctrl+R / F5` 啟動渲染、`Ctrl+Shift+A` 切換進階設定）。
- 提供功能設定雙向同步，在選單調整的選項將即時反映至主介面元件。

### 2. 快捷工具列 (SVG ToolBar)
- 新增輕巧精緻的頂部快捷工具列，全面採用高品質 SVG 向量圖示取代文字，不佔多餘版面。
- 每個工具列按鈕皆提供詳細的功能說明 ToolTip 與快捷鍵提示，一鍵快速執行常用操作（選擇 GPX、開啟媒體管理、執行效能測試、清除快取、檢視 Log、切換進階設定與啟動渲染）。

### 3. 版面大幅瘦身與彈性收合 (Space Saving)
- **支援收合 Worker 子進度條**：在「檢視」選單中可自由隱藏各 Worker 子進度條，為中小螢幕節省超過 180px 的垂直高度。
- **操作列介面精簡**：底端操作區移除多餘按鈕，聚焦於主要渲染控制。
- **純文字專業設計**：全面移除介面 Emoji，呈現專業清爽的桌面應用程式風格。
