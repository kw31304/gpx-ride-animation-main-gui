## 打卡點進出站平滑緩動（Ease-In-Out Deceleration & Acceleration）

- 擬真進出站緩動演算法：以 C1 連續三次 Hermite 曲線（Smoothstep）為基礎，軌跡接近照片打卡點前 1.5 秒平滑減速停靠，播放完畢後 1.2 秒平滑起步加速，徹底消除定格急煞與瞬間彈射的頓挫感。
- 全風格與全視角模式支援：全面套用至 2D North-Up、2D Heading-Up、3D-Terrain 與所有地圖風格，鏡頭旋轉運鏡與速度儀表 HUD 數值自然平順過渡。

### 主進度條即時渲染計時器

- 專屬計時標籤：主進度條正上方整合即時「渲染計時器」，以 HH:MM:SS 格式實時跳動顯示渲染經過時間。
- 總耗時保留：渲染完成、中止或基準測試結束時，精確保留最終總耗時於介面與日誌中。

### 本機磁碟底圖快取再利用率追蹤

- 即時快取命中統計：底圖預載與 DEM 讀取時自動攔截並記錄本機快取命中（Hits）與遠端下載（Misses）次數。
- 快取再利用效益量化：於終端機與 Log 檔案輸出「本機快取再利用率（Hit Rate %）」，清楚掌握本機圖資重複利用成效。

### 渲染完成詳細數據與參數報告

- 結構化總結報告：渲染完成後於 Log 檔結尾自動記錄四大分類完整報告：
  1. 路線與騎乘統計數據（GPX 路徑、總里程、累積爬升、GPS 點數）
  2. 底圖預熱與快取統計（預熱耗時、局部網格區塊數、快取再利用率、新增圖資容量、快取總容量、模式與上限）
  3. 渲染效能與輸出結果（輸出影片大小、畫面規格、時長構成、編碼器品質、多程序配置、各階段耗時、主渲染與全流程平均速率）
  4. 完整設定參數清單（40+ 項所有 config 參數詳細對齊清單）
