# 更新日誌 - 2026-08-22 17:05

## 🛠️ 修改與新增功能重點記錄

本版本將專案打包、發布腳本與公開發布說明歷史統整至專屬管理目錄 `release_tools/`，並開發全新 PySide6 視覺化管理介面 (`release_manager_gui.py`)：
1. **專屬打包發布目錄 (`release_tools/`)**：搬移 `build_exe.py`、`publish_release.py`、`build_exe.bat` 與 `release_notes/` 至專屬資料夾，保持根目錄乾淨清爽。
2. **全新 Release Manager 視覺化管理中心 (`release_manager_gui.py`)**：整合環境狀態檢測、一鍵打包 EXE & ZIP、發布說明 Markdown 編輯器與 GitHub Releases 一鍵發布。
3. **規範文件更新 (`instruction.md`)**：更新雙軌流程之發布說明目錄指針至 `release_tools/release_notes/`。

---

### 邏輯變更 (Logic)
* **專案路徑自適應校正 (`release_tools/build_exe.py` & `release_tools/publish_release.py`)**：
  - `build_exe.py`：新增自適應 `project_root` 偵測，無論由根目錄或 `release_tools/` 內部執行，皆能精確定位專案根目錄、虛擬環境與產出 `dist/`。
  - `publish_release.py`：更新 `load_release_notes()` 搜尋優先序，優先讀取 `release_tools/release_notes/`，兼顧舊版向下相容。
* **Release Manager 後端執行緒 (`release_tools/release_manager_gui.py` -> `WorkerThread`)**：
  - 以 `QThread` 搭配非阻塞串流管線執行 PyInstaller 打包與 GitHub REST API 發布作業，即時擷取命令列輸出並發送信號至 UI 控制台。
* **發布說明儲存與新增邏輯**：
  - 支援自動掃描 `release_tools/release_notes/` 歷史檔案，並能以當前時間戳自動產生範本草稿與即時覆寫儲存。

---

### 介面與體驗 (UI/UX)
* **Release Manager 主視窗 (`ReleaseManagerWindow`)**：
  - **頂部環境狀態面板**：即時顯示目前版本號（自動讀取 `gpx_renderer/__init__.py`）、Python 虛擬環境路徑、PyInstaller 安裝狀態、FFmpeg 核心路徑、GitHub Token 授權狀態（自動遮罩）與目標發布倉庫。
  - **EXE 打包管理分頁**：提供「🔨 開始一鍵打包 EXE & ZIP 壓縮包」、「📂 開啟 dist 輸出資料夾」與「▶️ 測試啟動打包好的 EXE」操作按鈕，支援自訂快取清理與自動開啟目錄。
  - **發布說明管理分頁**：下拉式歷史檔案選擇器、內建 Consolas 等寬字體 Markdown 編輯器與「➕ 新增新版說明」、「💾 儲存修改」按鈕。
  - **GitHub Releases 發布分頁**：提供 Tag 標籤、標題、ZIP 檔案瀏覽與防呆確認對話框，一鍵非同步發布至 GitHub。
  - **即時終端輸出控制台 (Terminal Output)**：黑色高對比控制台、自動滾動輸出日誌、進度條狀態呈現，並提供「🧹 清空日誌」與「📋 複製日誌」功能。
* **快速啟動批次檔 (`release_tools/run_release_manager.bat`)**：
  - 支援雙擊自動調用專案 `.venv` 虛擬環境啟動管理介面。
