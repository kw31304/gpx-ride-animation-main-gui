# 更新日誌 - 2026-08-25 23:00 (V1.3.5)

## 邏輯變更 (Logic)

1. **GUI 架構模組化與 UI/邏輯層全面分離**：
   - 將原先龐大單一檔案（`qt_app.py`、`qt_media_dialog.py`、`qt_video_trim_dialog.py`）拆解並重構成各具職責的專屬模組資料夾：
     - **主視窗專屬模組 (`main_window/`)**：分離出純 UI 定義 (`ui_main_window.py`)、視窗控制器 (`main_controller.py`)、專屬背景工作執行緒 (`main_workers.py`) 與進度儀表板組件 (`components/`)。
     - **媒體管理彈窗專屬模組 (`media_dialog/`)**：分離出視窗控制器 (`media_dialog_controller.py`)、Google Map 瓦片下載 Worker (`map_worker.py`)、向量路線畫布 (`widgets/route_preview_widget.py`) 與圖片預覽元件 (`widgets/clickable_preview.py`)。
     - **影片裁剪彈窗專屬模組 (`video_trim_dialog/`)**：分離出視窗控制器 (`video_trim_controller.py`) 與 OpenCV 影片解碼/分析引擎 (`video_player_engine.py`)。
   - 原路徑保留輕量透明向後相容層 (Shims)，確保外部呼叫與現有套件匯入 100% 相容。

2. **自定義圓形進度條 (`PyCircularProgress`) 升級與無縫對接**：
   - 修正幾何繪製問題：計算 `side = min(w, h) - progress_width` 並居中繪製，確保在長寬比不一時始終維持正圓不變形。
   - 補齊標準 `QProgressBar` API：實作 `setValue()`、`value()`、`setMaximum()`、`setMinimum()`、`reset()`，達成 Drop-in 替換。
   - 改用 `update()` 取代同步 `repaint()`，由 Qt 排程非同步重繪，大幅提升高幀率渲染更新時的 UI 順暢度。
   - 主進度更新與子程序 JSON 解析邏輯直接驅動圓形進度條。
