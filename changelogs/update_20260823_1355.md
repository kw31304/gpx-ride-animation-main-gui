# 更新日誌 - 2026/08/23 (個別停留秒數、相片預設、影片原始時長與可視化裁剪視窗)

## 📌 功能亮點

1. **全新獨立影片裁剪與播放預覽視窗 (`QtVideoTrimDialog`)**：
   - 點擊「`✂️ 裁剪影片頭尾 / 播放預覽...`」或雙擊影片項目的「停留秒數」欄位，立即彈出專屬視窗。
   - **視窗內即時 30 FPS 播放預覽**：提供 `[▶ 播放 / ⏸ 暫停]`、`[⏹ 停止]`、進度滑桿與當前時間戳。
   - **頭尾雙滑桿時間軸調整**：
     - **🟢 起點滑桿 (Start Time Slider)** + 數字微調框 (`spin_start`)。
     - **🔴 結束點滑桿 (End Time Slider)** + 數字微調框 (`spin_end`)。
     - 拖曳滑桿時畫面即時 Seek 跳轉至指定畫格。
   - **快捷操作按鈕**：
     - `[⏮ 設當前為起點]`、`[⏭ 設當前為結束]`。
     - `[🔄 還原全片長度]`、`[⚡ 前 3 秒]`、`[⚡ 前 5 秒]`。
   - **非破壞性時間軸設計 (Non-destructive)**：只儲存 `clip_start_sec` 與 `popup_duration`，完全不修改、不壓縮或覆蓋原片。

2. **媒體個別停留秒數與智慧預設機制**：
   - **📷 相片**：預設停留 3.0 秒（可個別修改或調整對話框頂部預設值）。
   - **🎬 影片**：預設保留影片原始片長（例如 10 秒影片預設 10 秒），亦可透過裁剪視窗任意截取片段。
   - **一鍵重設按鈕**：`[⚡ 一鍵套用 (相片預設 / 影片全片)]` 方便快速批次重設。

3. **路線媒體管理器 8 欄位列表與精準統計**：
   - 欄位包含：`["檔名", "類型", "影片長度", "停留秒數", "拍攝時間", "匹配里程 (km)", "自訂說明", "操作"]`。
   - 「停留秒數」呈現如 `4.5s (02.0~06.5s)` 或 `10.0s (全片)` 或 `3.0s`。
   - 頂部統計列與主介面即時精準加總：`總增加秒數 = Σ (各相片秒數 + 各影片裁剪後秒數)`。

4. **渲染引擎與硬體解碼最佳化**：
   - `RideRenderer` 在抵達景點時，自動由 `clip_start_sec` 快速跳轉擷取指定長度的動態連續畫格。
   - 長影片截取短片段時，僅解碼需要的秒數，完全不影響渲染速度與記憶體。
