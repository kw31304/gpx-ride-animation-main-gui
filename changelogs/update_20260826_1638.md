# 更新日誌 - 2026-08-26 16:38 (V1.3.5)

## 介面與體驗 (UI/UX)

1. **渲染進度分頁進度條全面升級為圓形進度環**：
   - 將「渲染進度」分頁中的主進度條 (progressBar_main) 及 6 個 Worker 子進度條 (progressBar_worker_1 ~ progressBar_worker_6) 全面替換為自定義圓形進度條 (PyCircularProgress)。
   - 主進度條設定直徑 110×110 px、線寬 10px、字級 14pt，採用科技青藍色光環 (#00adb5) 與立體陰影。
   - 各 Worker 子進度條設定直徑 65×65 px、線寬 6px、字級 11pt，採用亮藍色光環 (#2196f3) 與立體陰影。

2. **Windows 系統深色 / 淺色主題自動偵測與自適應配色**：
   - PyCircularProgress 導入三層式系統主題偵測機制（Qt 6 ColorScheme -> Palette 背景亮度 -> Windows 登錄檔 AppsUseLightTheme）。
   - **百分比文字配色**：
     - **深色模式**：純白文字 (#ffffff)，在深色背景下保持明亮清晰。
     - **淺色模式**：高對比深墨藍黑文字 (#1e293b)，徹底解決淺色主題下白底白字看不清的問題。
   - **背景軌道配色**：
     - **深色模式**：深灰底軌 (#2b2d42)。
     - **淺色模式**：俐落淺灰底軌 (#e2e8f0)。
   - **動態即時響應**：覆寫 changeEvent(PaletteChange)，在 Windows 系統切換主題時無需重啟即時變換配色。
