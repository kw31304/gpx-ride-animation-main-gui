# 更新日誌 - 2026-08-19

## 🛠️ 修改與新增功能重點記錄

### 1. 新增「戶外等高線 (Strava 風格)」與「山岳地形 (Google Terrain)」底圖風格 (`config.py`, `qt_app.py`, `qt_media_dialog.py`)
- **戶外等高線 (Strava 風格 / OpenTopoMap)**：
  - 於全域 `MAP_STYLE_OPTIONS` 加入 `OpenTopoMap` 戶外等高線圖資（編號 5）。
  - 完整呈現綠色山林植被、立體等高線（標註 250m、350m 等高線數字）、山頭峰名、水系溪流與繁體中文聚落地名，搭配 `3D-Terrain` 視角模式可完美重現 Strava 3D 騎乘動畫質感。
- **山岳地形 (Google Terrain)**：
  - 於全域 `MAP_STYLE_OPTIONS` 加入 Google Terrain 地形圖資（編號 6）。
  - 具備 Google 高解析度立體陰影山貌與極為豐富的在地化繁體中文縣市、鄉鎮市區、村里、山岳與路網標籤。
- **媒體管理器全面同步**：
  - 於 `qt_media_dialog.py` 的 `MAP_PROVIDERS` 同步新增「戶外等高線 (OpenTopoMap)」，讓使用者在相片與影片 GPS 路線對齊面板中亦可自由切換戶外等高線圖資。

### 2. 多程序渲染前置底圖下載（Prefetch）進度回傳與 UI 即時聯動 (`map_utils.py`, `qt_app.py`)
- **進度即時 JSON 串流**：
  - 於 `prefetch_route_basemap_chunks()` 預熱下載全路線所需切片時，即時發布帶有 `stage: "prefetch"` 的結構化 `[PROGRESS_JSON]` 負載。
- **GUI 狀態無縫切換**：
  - GUI 主視窗接收到預熱進度時，進度條立即動態更新（顯示 `底圖區塊: x / y`、`預先下載底圖中 (xx%)`），並同步更新各 Worker 待命狀態，徹底消除渲染啟動初期的停頓感。
