# 更新日誌 - 2026-08-23 13:05

## 🛠️ 修改與新增功能重點記錄

優化路線媒體管理器與主介面時長統計聯動：
1. **主介面即時總時長聯動更新**：當啟用路線媒體、加入照片/影片或修改每張停留秒數時，主視窗即時計算並呈現：`基礎騎乘時長 + 媒體停留增加秒數 (含影片獨立增加秒數) + 結尾拉遠定格 = 預估總時長`。
2. **媒體清單新增「影片長度」欄位**：在路線媒體管理器表格新增獨立欄位，影片清晰標註時間長度（如 `15.2s` 或 `01:23`），相片標註 `--`。
3. **支援多種匯入模式（單選/複選照片、影片、整個資料夾）**：
   - 支援在主介面或對話框內透過「➕ 新增照片/影片 (可多選)」一次選取多個檔案。
   - 支援透過「📁 新增資料夾」批次載入整個資料夾。
   - 核心 `scan_media_files()` 支援字串分號 `;` 分隔、路徑清單與目錄遞迴等多種混合格式。
4. **即時統計媒體與影片增加秒數**：在媒體管理器頂部新增統計資訊列，即時動態統計 `相片數量`、`影片數量`、`停留總增加秒數` 與 `影片增加秒數`。

### 邏輯變更 (Logic)
* **核心媒體模組 (`gpx_renderer/core/media.py`)**：
  - `MediaItem` 新增 `duration_sec` 屬性與 `duration_str` 格式化屬性。
  - `parse_video_metadata()` 擴充支援透過 OpenCV VideoCapture、ffprobe 與 ffmpeg 自動萃取影片長度。
  - `scan_media_files()` 擴充支援傳入單一字串、分號分隔字串或 `list[Path | str]` 混合清單，並自動進行路徑去重。
* **媒體管理對話框 (`gpx_renderer/gui/qt_media_dialog.py`)**：
  - 表格擴充為 7 欄：`["檔名", "類型", "影片長度", "拍攝時間", "匹配里程 (km)", "自訂說明", "操作"]`。
  - 新增 `_on_add_files()` 與 `_on_add_folder()` 按鈕方法。
  - 新增 `_update_stats_summary()` 即時計算相片與影片增加秒數。
* **主視窗介面 (`gpx_renderer/gui/qt_app.py`)**：
  - `browse_media()` 彈出選單支援複選檔案與選擇資料夾。
  - `_update_dashboard_summary()` 動態計算媒體停靠增加秒數並即時刷新主視窗儀表板與 GPX 距離/時長欄位。
