# 更新日誌 - 2026-08-25 17:02 (V1.3.4)

## 邏輯變更 (Logic)

1. **選單與工具列動作管理架構 (`MainWindow._init_toolbar_and_menus`)**：
   - 實作 `QMenuBar` 與 `QToolBar` 的完整動作連結與生命週期管理。
   - 支援雙向信號連動機制（Two-Way Synchronization）：
     - 資訊面板（`action_show_speed`、`action_show_minimap`、`action_show_elevation`）與主畫面核取方塊雙向同步。
     - 渲染與鏡頭特性（`action_dynamic_speed_zoom`、`action_real_speed`、`action_basemap`、`action_parallel`、`action_enable_media`、`action_preview`）與主畫面設定雙向同步。
     - 快取模式（`action_cache_session`、`action_cache_persistent`）透過 `QActionGroup` 互斥群組與 `combo_cache_mode` 下拉選單即時雙向連動。
     - 預設畫質風格（`action_profile_fast`、`action_profile_balanced`、`action_profile_quality`）即時切換 `combo_profile_2` 並套用參數。
2. **進階設定與面板動態折疊控制**：
   - 擴充 `toggle_advanced()` 同步連動 `action_toggle_advanced` 狀態。
   - 實作 `_on_toggle_summary(visible)` 與 `_on_toggle_workers(visible)`，允許使用者自由收合「渲染設定摘要」與「各 Worker 子進度條」，自適應調整視窗高度。
3. **程序狀態同步與防呆 (`set_running`)**：
   - 工具列與選單上的 `action_start_render`、`action_stop_render`、`action_benchmark` 即時依渲染執行狀態啟用或停用。
4. **輔助對話框實作**：
   - 實作 `show_shortcuts_dialog()` 呈現所有功能快捷鍵清單。
   - 實作 `show_about_dialog()` 呈現版本與系統資訊。

## 介面與體驗 (UI/UX)

1. **頂部選單列 (`QMenuBar`)**：
   - 建立五大核心選單：
     - **檔案 (`&F`)**：選擇 GPX 檔案 (`Ctrl+O`)、指定輸出影片 (`Ctrl+S`)、選擇路線媒體、開啟媒體管理器 (`Ctrl+M`)、開啟 Log 資料夾 (`Ctrl+L`)、結束程式 (`Ctrl+Q`)。
     - **編輯與工具 (`&E`)**：效能測試 / Auto Tune (`Ctrl+T`)、套用 Auto Tune 建議、清除本機快取、重新整理 GPX 距離與時長 (`F5`)。
     - **檢視 (`&V`)**：切換顯示工具列、進階設定面板 (`Ctrl+Shift+A`)、設定摘要面板、各 Worker 子進度條。
     - **設定 (`&S`)**：預設畫質風格子選單、資訊面板子選單、鏡頭與渲染特性開關、地圖快取模式子選單。
     - **說明 (`&H`)**：快捷鍵與使用手冊 (`F1`)、關於 GPX Ride Renderer。
2. **快捷工具列 (`QToolBar`)**：
   - 採用純 SVG 向量圖示取代文字標籤（`ToolButtonIconOnly`），節省水平與垂直空間。
   - 包含：選擇 GPX、媒體管理、效能測試、清除快取、Log 資料夾、進階設定切換、開始渲染、停止渲染。
   - 每個圖示均配置詳細功能解說與快捷鍵 ToolTip。
3. **版面高度與元件精簡**：
   - 移除底部操作列中的「開啟 Log 資料夾」按鈕（已整合至頂部選單與工具列），底部操作列專注於「開始渲染」與「停止」。
   - 支援折疊各 Worker 子進度條，為筆電螢幕大幅節省垂直高度。
4. **全面移除 Emoji 字元**：
   - 介面中所有文字標籤、按鈕、選單項目、訊息對話框與狀態列提示均全面改為乾淨專業的純文字。
