# 更新日誌 - 2026-08-21 17:45

## 🛠️ 修改與新增功能重點記錄

本版本全面重構並優化「路線媒體管理器」(`QtMediaManagerDialog` 與 `QtRoutePreviewWidget`)：
1. 引進 Viewport 動態可視範圍高解析 Google 街道底圖瓦片下載機制，解決地圖放大拉近模糊問題。
2. 消除切換直式/橫式相片時頂部外框忽高忽低排版抖動，並平滑化媒體刪除流程。
3. 新增「路線位置滑桿」及清單欄位直接雙擊編輯手動里程，全面改採即時自動儲存與雙向同步，移除手動套用按鈕。
4. 向量化軌跡繪製與 $O(1)$ 快速座標插值，實現以游標為中心的高流暢度平滑縮放。

---

### 邏輯變更 (Logic)
* **媒體過濾與排除邏輯 (`gpx_renderer/core/media.py`)**：
  - 更新 `scan_media_files()`：讀取 `media_overrides.json` 時，自動過濾並略過標記為 `excluded: True` 或 `deleted: True` 的檔案，使刪除項目在後續掃描與影片渲染中被完全排除。
* **向量路線預覽畫布 (`gpx_renderer/gui/qt_media_dialog.py` -> `QtRoutePreviewWidget`)**：
  - 底圖全面改用 Google 街道圖（Roadmap），實作 `compute_auto_zoom_level()` 依據當前比例尺自動計算最佳層級（Level 10 ~ 19）。
  - 新增 `_do_fetch_viewport_basemap()` 與 200ms 防抖 `QTimer`，依據當前視窗中心與邊界動態抓取高解析瓦片，搭配 `SmoothPixmapTransform` 消除過渡鋸齒。
  - 新增 `_get_km_world_coord(km)`：以 C 底層 `np.interp` 取代逐畫格全陣列 `np.argmin`，將畫格內座標換算時間降至微秒級。
  - 向量化主軌跡線渲染：改以 `QPolygonF` 搭配 Qt 原生 `painter.drawPolyline()` 進行雙層光暈批次繪製，大幅降低 CPU 負載。
  - 改進 `wheelEvent`：以滑鼠游標所在的地理世界座標為錨點平滑縮放，提供自然流暢的縮放導航體驗。
* **媒體管理器對話框 (`gpx_renderer/gui/qt_media_dialog.py` -> `QtMediaManagerDialog`)**：
  - 實作平滑單列刪除機制（`table.removeRow`）與按鈕事件閉包動態重綁，刪除後自動推進並即時刷新右側預覽卡片與地圖視野。
  - 實作表格直接編輯事件（`_on_table_item_changed`）：雙擊表格第 3 欄（匹配里程）或第 4 欄（自訂說明）可直接鍵入修改，自動同步至右側控制項與地圖標記。
  - 移除 `_apply_current_edit` 與「套用此項修改」按鈕，改為即時自動儲存與雙向同步（`_on_manual_km_toggled`, `_on_manual_km_value_change`, `_on_slider_km_value_change`, `_on_caption_text_changed`）。

### 介面與體驗 (UI/UX)
* **媒體清單列表 (`self.table`)**：
  - 擴展為 6 欄架構：`["檔名", "類型", "拍攝時間", "匹配里程 (km)", "自訂說明", "操作"]`。
  - 第 3 欄「匹配里程」與第 4 欄「自訂說明」支援雙擊直接手動輸入編輯。
  - 第 5 欄新增個別 `🗑️ 刪除` 項目按鈕，點擊彈出確認對話框並自本次清單排除。
* **路線預覽畫布工具列**：
  - 移除「縮放層級」下拉選單與標籤，保留最核心的 `[➕ 放大]`、`[➖ 縮小]` 與 `[🔄 視野置中]` 工具按鈕。
  - 左下角底圖浮水印簡化為乾淨純粹的 `Google Maps 街道圖` 標記。
* **右側「編輯選取相片屬性」卡片**：
  - 新增「路線位置滑桿 (`slider_manual_km`)」，支援直覺沿著路線拖拉並即時驅動地圖標記與氣泡框移動。
  - 移除「套用此項修改」按鈕，任何屬性變動皆即時反饋儲存。
* **版面抖動與外框忽高忽低消除**：
  - 固定相片縮圖容器高度為 210px（`lbl_preview_image.setFixedHeight(210)`），使直式/橫式照片縮放時絕不改變容器尺寸。
  - 設定頂部「媒體播放與相機時間校正」群組及右側各卡片為 `QSizePolicy.Fixed` 垂直尺寸策略，徹底杜絕切換選取時介面高度劇烈震盪。
