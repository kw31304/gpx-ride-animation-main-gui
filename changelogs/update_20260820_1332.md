# 更新日誌 - 2026-08-20 13:32

## 🛠️ 修改與新增功能重點記錄

本版本優化打包與發布流程，實作自動版本解析、ZIP 自動壓縮，並將 GitHub Releases 發布功能獨立為專用腳本，支援打包後先本機測試再手動發布。

---

### 邏輯變更 (Logic)
* **打包腳本自動版本解析與壓縮 (`build_exe.py`)**：
  - 新增 `detect_version()` 函式，自動從 `qt_app.py` 中的 `setWindowTitle` 解析目前版本號（如 `v1.3.0`），使打包版本自動同步。
  - 新增 `compress_to_zip()` 函式，於 PyInstaller 打包完成後，自動將 `GPX_Ride_Renderer` 資料夾壓縮為標準發行壓縮檔（如 `GPX_Ride_Renderer_v1.3.0_windows_x64.zip`）。
  - 將 GitHub 上傳邏輯解耦獨立，打包完成後提供明確指引供使用者進行本機測試。
* **獨立 GitHub Releases 發布腳本 (`publish_release.py`)**：
  - 新增專用的手動發布腳本 `publish_release.py`。
  - 支援從 `.env` 檔案載入 `GITHUB_TOKEN` 與公開倉庫名稱 (`kw31304/gpx-ride-animation-releases`)。
  - 發布前提供互動式確認提示 (`[Y/n]`)，避免誤觸發布。
  - 透過 GitHub REST API 自動建立對應版本標籤 (Tag) 的 Release、處理同名 Asset 覆蓋，並支援新倉庫自動初始化功能。
  - 上傳完成後於終端機輸出 Release 頁面與公開下載連結。
* **安全防護設定 (`.gitignore`)**：
  - 將 `.env` 與 `*.env` 納入 `.gitignore`，確保包含 GitHub Token 之私密設定檔不會被提交至版本控制。
