# 更新日誌 - 2026-08-19 16:36

## 🛠️ 修改與新增功能重點記錄

本版本完成了「路線底圖與高程圖資磁碟快取管理系統 (方案 A+B 整合)」：支援 Session 自動暫存（關閉程式時自動清除）與 Persistent 永久保留雙模式，並具備 LRU 自動容量上限修剪 (預設 1GB) 與 GUI 一鍵手動清除快取功能。

---

### 邏輯變更 (Logic)
* **新增快取管理核心模組 (`CacheManager` in `gpx_renderer/core/cache_manager.py`)**：
  - 統一於主程式根目錄 `.map_cache/` 建立圖資快取管理系統。
  - 支援 `session`（暫存於 `.map_cache/session_<pid>_<timestamp>/`）與 `persistent`（永久存放於 `.map_cache/persistent/`）雙模式切換。
  - 提供 `prune_if_exceeds(max_mb=1024, target_mb=800)`：依檔案最後訪問時間 (Access Time / `os.utime`) 由舊至新實作 LRU 智慧淘汰機制，確保硬碟空間受控在 1GB 以內。
  - 提供 `cleanup_current_session()` 與 `cleanup_orphan_sessions()`：主程式結束時精確清除當次 Session 暫存，啟動時自我修復清理異常中斷之殘留暫存。
  - 提供 `cleanup_all_cache()`：一鍵完整清空所有本機磁碟快取。
* **高程圖資快取升級 (`gpx_renderer/core/dem_utils.py`)**：
  - 將 DEM Tile 下載改由 `CacheManager.get_dem_dir()` 統一管理，加入多行程安全之原子寫入 (Atomic Write via `.tmp`) 與讀取時 LRU 時間戳記更新 (`touch_file`)。
* **底圖切片快取升級 (`gpx_renderer/core/map_utils.py`)**：
  - 於 `_fetch_raster` 啟動時註冊 `CacheManager.get_tiles_dir()` 給 `contextily`，並在 `prefetch_route_basemap_chunks()` 預熱完成後自動觸發 LRU 容量上限安全檢查。
* **多程序 Worker 與子程序配置同步 (`gpx_renderer/core/parallel.py`, `gpx_renderer/config.py`)**：
  - 新增 `MAP_CACHE_MODE`、`MAP_CACHE_MAX_MB` 與 `MAP_CACHE_SESSION_ID` 全域參數與 `RUNTIME_CONFIG_KEYS` 註冊，確保所有平行的 Dynamic Worker 與子程序皆安全共享相同的 Session 目錄。

---

### 介面與體驗 (UI/UX)
* **主視窗 UI 檔案 (`main_window.ui`, `ui_main_window.py`)**：
  - 在進階設定群組面板 (`groupBox` 之 `verticalLayout_4`) 新增：
    - `combo_cache_mode` (QComboBox)：提供「自動暫存 (關閉清除)」與「永久保留 (保留快取)」下拉選項。
    - `lbl_cache_size` (QLabel)：即時呈現磁碟快取容量（如 `快取: 0.0 MB`）。
    - `btn_clear_cache` (QPushButton)：提供「清除快取」按鈕，點擊後跳出確認對話框並一鍵清空磁碟快取。
* **主視窗控制器 (`MainWindow` in `gpx_renderer/gui/qt_app.py`)**：
  - 新增 `refresh_cache_size_display()`、`on_cache_mode_change()` 與 `on_clear_cache_clicked()` 槽函數。
  - 在 `_update_dashboard_summary()` 的效能資訊標籤 (`label_cfg_perf`) 中即時呈現目前所選之快取模式。
  - 在 `closeEvent` 中加入生命週期保護：當處於 Session 模式時，關閉視窗即自動調用 `CacheManager.cleanup_current_session()` 完成無痕清理。
  - 在 `_finish_proc` 渲染完成後自動刷新 `lbl_cache_size` 快取容量顯示。
