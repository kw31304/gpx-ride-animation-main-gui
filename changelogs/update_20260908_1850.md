# 更新日誌 - 2026-09-08 18:50

## 核心邏輯與修復 (Core & Bug Fixes)

1. **修復軌跡顏色「經典橘」誤判為「速度漸層」重大問題**：
   - **問題根因**：在 `renderer.py` 的 `_build_track_colors()` 函式中，原本的比對條件為 `if "Strava" in scheme:`；但介面與設定傳入的名稱為「`經典橘`」（不含 `"Strava"` 字串），導致條件為假且後續純色分支均未命中，最終落入 `else:` 分支被強制使用 `plasma` 顏色映射表生成速度漸層熱圖。
   - **修復措施**：重構 `_build_track_colors()`，將「速度漸層」獨立為明確比對分支（`elif "速度漸層" in scheme:`）；將「經典橘」、「橘」與「Strava」明確比對為純橘色 `(252, 76, 2)`；若遇到未知名稱則安全回退為經典橘純色。
   - **多程序序列化同步**：在 `config.py` 的 `RUNTIME_CONFIG_KEYS` 中補上 `"TRACK_COLOR_SCHEME"`，確保多程序渲染（Parallel Render）時設定能完整傳遞至所有 Worker 子程序。

2. **未載入 GPX 切換分頁崩潰與繪圖安全防護**：
   - 修復未載入 GPX 軌跡檔案時切換至媒體分頁拋出 `AttributeError: 'NoneType' object has no attribute 'route_center_x'` 的崩潰例外。
   - 在 `route_preview_widget.py` 的 `paintEvent` 與 `reset_view` 增加 `self.ride_data is None` 防護；同時修復 `QPainter` 提前返回時的生命週期管理，解決 `QBackingStore::endPaint() called with active painter` 警訊。

3. **渲染預設值全面調整**：
   - **地圖風格**：預設改為「**4. 衛星影像**」(`Esri.WorldImagery`)。
   - **視角模式**：預設改為「**3D 真地形**」(`3D-Terrain`)。
   - **View Margin**：預設改為 **`800.0`**（視距更緊湊、立體感更強）。
   - **輸出解析度**：預設改為 **`1080p 直式 (1080×1920)`**。
   - 全面同步 `config.py`、`main_controller.py`、`media_tab_controller.py` 及 `media_dialog_controller.py` 的初始值與回退常數。
