# 更新日誌 - 2026-08-21 16:31

## 🛠️ 修改與新增功能重點記錄

本版本更新專案發布腳本 `publish_release.py` 與工作流程指引 `instruction.md`，使 GitHub Release 發布流程支援讀取 `release_notes/` 資料夾歷程檔案、增強版本號匹配正則、加入網路請求逾時防護與支援免互動發布參數。

---

### 邏輯變更 (Logic)
* **發布腳本增強 (`publish_release.py`)**：
  - 更新 `load_release_notes()`：優先讀取 `release_notes/` 資料夾中最新命名的 Markdown 檔案（如 `release_YYYYMMDD_HHMM.md`），並向下相容根目錄下的 `release_notes.md`。
  - 更新 `detect_version()`：改用 `r'__version__\s*=\s*["\']([^"\']+)["\']'` 正則匹配，支援語義化版本與預發布後綴。
  - 新增命令列參數解析 `parse_args()`：支援 `-y` / `--yes`（免確認直接發布）、`--repo` 與 `--version`。
  - 加入網路請求超時設定（API 請求 30s，ZIP 上傳 300s），防止連線停頓或網路不穩時行程無窮卡死。
  - 增加輸出壓縮檔尋找備援路徑（支援 `gpx-ride-animation-releases/` 與 `dist/`）。
* **規範更新 (`instruction.md`)**：
  - 確立雙軌記錄流程（`changelogs/update_YYYYMMDD_HHMM.md` 與 `release_notes/release_YYYYMMDD_HHMM.md`）。
  - 明確規範「公開發布說明」僅限主程式功能新增、修復、效能與 UI/UX 改善時撰寫，內部建置與腳本異動不列入。
  - 明定提交前語法檢查與 Conventional Commits 格式規範。
