# 更新日誌 - 2026-08-22 17:10

## 🛠️ 修改與新增功能重點記錄

本版本將打包發行產出路徑全面定向至 `D:\gpx-ride-animation-releases`，並加入 PyInstaller 打包完成後自動刪除 `build/` 中間暫存資料夾之自動清理機制：
1. **發行產出目錄定向 (`D:\gpx-ride-animation-releases`)**：`build_exe.py` 與 `release_manager_gui.py` 預設輸出並存取 `D:\gpx-ride-animation-releases`，支援 EXE 產出、ZIP 壓縮與 GitHub 發布資產讀取。
2. **自動清理 `build/` 編譯暫存資料夾**：在 PyInstaller 打包與 ZIP 壓縮完成後，自動執行 `shutil.rmtree()` 刪除 `build/` 暫存資料夾，大幅節省專案磁碟空間。
